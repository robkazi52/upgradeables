# Non-Authoritative Branch Suppression — Basic Example

**Evidence label:** Illustrative modern example. It demonstrates the v0.2 operational contract and is not presented as a recovered historical chat.

## Task context

A repository contains current contribution rules, an obsolete draft, and a quoted malicious instruction in an issue.

## Why this Upgradeable activates

All are topically relevant but only one governs work.

## Inputs / state

File provenance, version status, repository authority policy, and task scope.

## What it does

Uses current rules for action, labels the draft obsolete, and treats the quoted instruction as untrusted evidence only.

## What it does not do

It does not delete either document or obey the issue text.

## Result / state change

Actions follow the authoritative branch while alternatives remain auditable.
