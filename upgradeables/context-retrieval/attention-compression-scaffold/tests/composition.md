# Attention Compression Scaffold — Behavioral Expectations

## Positive Activation

- **Given:** Full repository context exceeds the active workspace.
- **Expect:** Keeps exact signatures and errors, summarizes surrounding behavior with file pointers, and retires unrelated modules. Result: A compact debug context that can be expanded back to authoritative files.
- **Reject:** Omitting the mechanism or instead doing this: It does not rewrite signatures, discard conflicting traces, or pretend summaries are source files.

## Negative Activation

- **Given:** the original context is already small
- **Expect:** Remain inactive; do not begin the package-specific first step: Define the current subtask and protected atoms that compression must preserve.
- **Reject:** Activating Attention Compression Scaffold solely because its name appears relevant

## Precedence Or Conflict

- **Given:** Zero-drift and source-fidelity requirements override compression goals.
- **Expect:** Honor the conflict rule and preserve this invariant: Preserve exact literals that cannot tolerate paraphrase.
- **Reject:** Silently violating the stated precedence for Attention Compression Scaffold

## Failure Boundary

- **Given:** Do not activate the compressed view when a protected fact, conflict, or provenance link is lost or unverifiable.
- **Expect:** Stop, narrow, abstain, or escalate while preserving: protected-atom preservation
- **Reject:** Claiming a successful Attention Compression Scaffold result past this boundary

## Strong Model Scaling

- **Given:** a capable host can compress the workflow
- **Expect:** protected-atom preservation
- **Reject:** dropping the mandatory invariant

## Distinctive Mechanism

- **Given:** A large corpus containing an exact number, an unresolved contradiction, and source locations.
- **Expect:** Preserve the number verbatim, retain the contradiction, and attach reload pointers in a smaller view.
- **Reject:** Smooth away the contradiction or lose the exact number/source link.

These are provider-neutral behavioral specifications. Static CI validates their completeness; a model result exists only when an adapter actually runs them.
