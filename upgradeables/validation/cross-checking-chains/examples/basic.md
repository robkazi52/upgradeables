# Cross-Checking Chains — Basic Example

**Evidence label:** Illustrative modern example. It demonstrates the v0.2 operational contract and is not presented as a recovered historical chat.

## Task context

A dataset row is used to justify a product safety claim.

## Why this Upgradeable activates

Identity, extraction, interpretation, and corroboration must all hold in order.

## Inputs / state

Dataset version, row locator, calculation, paper, and safety threshold.

## What it does

Checks artifact identity, recomputes the value, tests claim entailment, then corroborates with an independent source.

## What it does not do

Count two pages quoting the same dataset as independent proof.

## Result / state change

The chain stops at a unit mismatch before the unsafe conclusion is released.

## Interaction with companion components

['critical-atomic-verification', 'citation-fidelity', 'truth-redundancy']
