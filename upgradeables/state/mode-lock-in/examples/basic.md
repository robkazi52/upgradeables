# Mode Lock-In — Basic Example

**Evidence label:** Illustrative modern example. It demonstrates the v0.2 operational contract and is not presented as a recovered historical chat.

## Task context

Transform policy text without changing meaning.

## Why this Upgradeable activates

Creative rewriting would violate the requested transformation mode.

## Inputs / state

A fidelity-first mode with preserve-meaning and no-new-claims invariants.

## What it does

Checks each revision against the locked transformation contract.

## What it does not do

It does not drift into persuasive copywriting after seeing marketing language.

## Result / state change

A clearer document with preserved claims and traceable exceptions.
