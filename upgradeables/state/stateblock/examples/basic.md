# StateBlock — Basic Example

**Evidence label:** Illustrative modern example. It demonstrates the v0.2 operational contract and is not presented as a recovered historical chat.

## Task context

Three agents prepare, review, and publish a technical report.

## Why this Upgradeable activates

They need a shared current objective, source set, status, and unresolved-risk record.

## Inputs / state

Approved scope, authority rules, section owners, evidence index, and publish gate.

## What it does

Creates one versioned block and gives each agent a scoped view with controlled update rights.

## What it does not do

It does not let each agent maintain an independent final status.

## Result / state change

Coordination and validation use the same current task truth.
