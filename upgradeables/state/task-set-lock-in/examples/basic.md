# Task-Set Lock-In — Basic Example

**Evidence label:** Illustrative modern example. It demonstrates the v0.2 operational contract and is not presented as a recovered historical chat.

## Task context

Build and validate a public repository without changing the canonical source files.

## Why this Upgradeable activates

Many attractive documentation additions could distract from required build and validation outputs.

## Inputs / state

Required repository, validation gates, immutable source constraint, and publication condition.

## What it does

Locks those fields, gates work against them, and records any user-authorized scope change.

## What it does not do

It does not stop after scaffolding or rewrite the source corpus.

## Result / state change

Completion is evaluated against the original concrete specification.
