# Truth Redundancy — Basic Example

**Evidence label:** Illustrative modern example. It demonstrates the v0.2 operational contract and is not presented as a recovered historical chat.

## Task context

A high-impact numerical claim drives a decision.

## Why this Upgradeable activates

A single transcription or calculation error could change the outcome.

## Inputs / state

The source table and an independently reproduced calculation.

## What it does

Records both anchors and checks their independence.

## What it does not do

Treat two paragraphs citing the same table as independent.

## Result / state change

An anchor pair ready for Multi-Truth Gating.
