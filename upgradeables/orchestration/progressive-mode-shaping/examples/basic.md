# Progressive Mode Shaping — Basic Example

**Evidence label:** Illustrative modern example. It demonstrates the v0.2 operational contract and is not presented as a recovered historical chat.

## Task context

A product team moves from broad feature concepts to one implementation specification.

## Why this Upgradeable activates

Exploration is useful early but must not persist into engineering execution.

## Inputs / state

Candidate features, criteria, decisions, constraints, and current phase.

## What it does

Narrows from ideation to comparison to one plan, locking decisions at each transition.

## What it does not do

Does not keep rejected features active or force a premature choice without comparison.

## Result / state change

Engineering receives one precise specification with traceable retired alternatives.

## Interaction with companion components

StateBlock records locks; Anti-Tunnel Vision protects early comparison.
