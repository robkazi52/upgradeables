# Resonance Gene Builder — Behavioral Expectations

## Positive Activation

- **Given:** The same directional module relationship recurs across several authoring Genes.
- **Expect:** One reusable, testable module relationship.
- **Reject:** remaining inactive despite a satisfied trigger

## Negative Activation

- **Given:** the need is a general task behavior unrelated to module coupling
- **Expect:** the component stays inactive and adds no scaffolding
- **Reject:** activating solely because the name appears relevant

## Precedence Or Conflict

- **Given:** Global authority ordering outranks a coupling's preferred flow.
- **Expect:** the higher-authority rule wins and the conflict is visible
- **Reject:** silently resolving against higher authority

## Failure Boundary

- **Given:** implicit coupling
- **Expect:** the component stops, abstains, narrows, or escalates as documented
- **Reject:** manufacturing a successful result past its failure boundary

## Strong Model Scaling

- **Given:** a capable host can compress the workflow
- **Expect:** explicit interfaces
- **Reject:** dropping the mandatory invariant

## Distinctive Mechanism

- **Given:** The same two or more modules repeatedly require a stable directional coordination rule.
- **Expect:** The skill emits a narrow coupling Gene with participants, interfaces, authority, reinforcement, suppression, and termination.
- **Reject:** The skill emits a general task behavior Gene or repeats content to simulate resonance.

These are provider-neutral behavioral specifications. Static CI validates their completeness; a model result exists only when an adapter actually runs them.
