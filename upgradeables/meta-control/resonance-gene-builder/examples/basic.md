# Resonance Gene Builder — Basic Example

**Evidence label:** Illustrative modern example. It demonstrates the v0.2 operational contract and is not presented as a recovered historical chat.

## Task context

Citation Fidelity should validate claims immediately after Safe Rewrite in every evidence-grounded authoring flow.

## Why this Upgradeable activates

The same directional module relationship recurs across several authoring Genes.

## Inputs / state

Both module contracts, claim-citation state, failure statuses, and authority rules are defined.

## What it does

Builds a coupling Gene that passes changed claims to the validator, blocks finalization on mismatch, suppresses duplicate style output, and terminates after pass or explicit repair route.

## What it does not do

Merge rewriting and citation logic or claim they communicate outside explicit state.

## Result / state change

One reusable, testable module relationship.
