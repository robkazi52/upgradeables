# Reasoning-Scale Controller — Basic Example

**Evidence label:** Illustrative modern example. It demonstrates the v0.2 operational contract and is not presented as a recovered historical chat.

## Task context

Correct one citation in a long report whose architecture is already accepted.

## Why this Upgradeable activates

The surrounding artifact is large, but the actual defect is local and source-verifiable.

## Inputs / state

The correct source passage and locked report structure are available.

## What it does

Routes source verification to Subatomic, the citation replacement to Atomic, and avoids Cosmic redesign unless the correction exposes a section-wide provenance failure.

## What it does not do

Re-outline the report because the document is long.

## Result / state change

A proportional local correction with an explicit escalation condition.

## Interaction with companion components

['critical-atomic-verification', 'micro-repair']
