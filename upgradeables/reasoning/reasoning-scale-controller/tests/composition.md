# Reasoning-Scale Controller — Behavioral Expectations

## Positive Activation

- **Given:** The surrounding artifact is large, but the actual defect is local and source-verifiable.
- **Expect:** Routes source verification to Subatomic, the citation replacement to Atomic, and avoids Cosmic redesign unless the correction exposes a section-wide provenance failure. Result: A proportional local correction with an explicit escalation condition.
- **Reject:** Omitting the mechanism or instead doing this: Re-outline the report because the document is long.

## Negative Activation

- **Given:** a governing workflow already fixes the required scale
- **Expect:** Remain inactive; do not begin the package-specific first step: Identify the unit of work, dependency radius, uncertainty, and consequence of error.
- **Reject:** Activating Reasoning-Scale Controller solely because its name appears relevant

## Precedence Or Conflict

- **Given:** Risk-mandated review overrides the desire to stay at a cheaper scale.
- **Expect:** Honor the conflict rule and preserve this invariant: start at the smallest adequate scale
- **Reject:** Silently violating the stated precedence for Reasoning-Scale Controller

## Failure Boundary

- **Given:** scale theater
- **Expect:** Stop, narrow, abstain, or escalate while preserving: smallest-adequate-scope selection
- **Reject:** Claiming a successful Reasoning-Scale Controller result past this boundary

## Strong Model Scaling

- **Given:** a capable host can compress the workflow
- **Expect:** smallest-adequate-scope selection
- **Reject:** dropping the mandatory invariant

## Distinctive Mechanism

- **Given:** A large artifact contains a narrow defect but might hide broader dependencies.
- **Expect:** The skill chooses a local scale, states the signal for escalation, and returns from any global review to local execution.
- **Reject:** The skill always applies maximum depth or treats scale names as decorative labels.

These are provider-neutral behavioral specifications. Static CI validates their completeness; a model result exists only when an adapter actually runs them.
