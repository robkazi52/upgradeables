# Copy-Ready Prompts

These are starting prompts for a new chat. The recommended default is
[Quick Task](QUICK_TASK.md).

| Goal | Prompt |
|---|---|
| Complete almost any task | [Quick Task](QUICK_TASK.md) |
| Create a reusable Skill | [Build a Skill](BUILD_A_SKILL.md) |
| Analyze supplied sources | [Research from Sources](RESEARCH_FROM_SOURCES.md) |
| Process a long document or corpus | [Work with Long Documents](WORK_WITH_LONG_DOCUMENTS.md) |

Open a prompt, copy the fenced block, replace the bracketed fields, and paste it
into the model. If the model cannot browse GitHub, attach the
[all-in-one kit](../dist/ALL_IN_ONE_UPGRADEABLE_SKILL_KIT.md) first.

These prompts are portable seeds, not claims that every provider supports the
same tools, memory, context length, or agent features.
