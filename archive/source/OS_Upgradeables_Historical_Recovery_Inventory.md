# 7. ABF, ITFC, OCG, ECL — corrections and collisions


## ABF — Activation-Budget Funnel
**Status:** recovered correction to the September v1 catalog, where ABF had been left unresolved.

Recovered operating concept:
`retrieve → quote → index → transform → write → verify`

Recovered budget concept:
- Keep roughly **≤5–7 active pulls** in the live reasoning workspace.
- Raw knowledge retrieval and decision-making should not compete in the same step.
- Stage retrieval, evidence capture, transformation, composition, and verification.

Suggested modern Skill interpretation:
- Context / activation-budget controller.
- Use progressive disclosure.
- Limit simultaneous active source/module pulls.
- Move verified facts into compact indexed state before synthesis.

# 17. Deduplication rule for the merged Skills catalog


When merging historical entries into the modern catalog:
- If the historical name is exactly the same as a current entry, do not duplicate it.
- If it is a historical exact-name alias for a current concept, add it to an Alias / Provenance table.
- If it represents a materially distinct mechanism, add a new candidate Skill/Mode/Validator.
- If an acronym collides, split namespaces.
- If a historical numeric ID comes from a different registry generation, preserve the original date/version.
- Never reuse a historical ID for a later concept without a version qualifier.
